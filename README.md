# Food Image Recognition using ResNet

This project uses a ResNet model trained on the Food-101 dataset to classify food images.

## Model
- ResNet18 / ResNet50 (fine-tuned)
- Dataset: Food-101

## Features
- Upload image → predict food type
- Trained using transfer learning

## Tech Stack
- PyTorch
- Torchvision
- Google Colab
